# Tilt House: guide for AI agents (Claude Code, Codex)

You are evaluating or working on Tilt House, a casino tycoon on NEAR testnet where the player is the
house: owners open tables, rent seats by the hour and compete for 24 NPC gamblers with their own NEAR
wallets; a gambler close to choosing a player's table stops and asks its owner for one thing (lower
edge, higher max bet, boost) and sits there if the owner answers in time. Rent fills an on-chain
jackpot and every round is provably fair (track `games`). $TILT is its memecoin: minted to players on
days they beat the house, burned on days the house wins, burned together to start a Tilt Hour (track
`memecoins`). Human overview: `README.md`.

## Evaluate it

Node 22+, pnpm (`corepack enable` or `npm i -g pnpm`), Rust stable (plus `wasm32-unknown-unknown`
and `cargo-near` for the contract sandbox tests). No keys, no config: everything targets the public
testnet deployment.

```sh
pnpm install
pnpm judge                                                            # ~1 min, Node only: every Docker-free README claim, live; ends "18/18 passed", writes judge-report.json
pnpm --filter cli-demo floor                                          # the live economy right now
pnpm --filter cli-demo demo                                           # play on testnet (the first run makes a throwaway account), verify every round
pnpm --filter cli-demo poker                                          # two accounts play hold'em with the NPC bots, every hand verified
pnpm --filter cli-demo verify-session --player g-mia.tilthouse.testnet  # verify an NPC gambler's session
cargo run -p tilt-house-sim --release -- --days 7 --seed 42 --out /tmp/tilt-sim.json  # a simulated week
cargo run -p tilt-house-sim --release -- meme --days 60 --scenario busy > /tmp/tilt-meme.json  # 60 days of $TILT supply (JSON)
```

All CLI commands exit 0 only when every check passes; a failed check prints `✗` with the reason.
`demo` makes its own throwaway testnet account (key in `~/.tilt-house/cli-demo-account.json`) and
reuses it on later runs; `--new` makes a fresh one (the relayer activates a limited number per hour).
In a browser without logging in: https://tilt-house-beta.vercel.app/table/ada?demo=1 (any table) and
https://tilt-house-beta.vercel.app/poker?demo=1 play practice sessions with the real rules (local
seed, nothing on chain); the lobby, $TILT page and live feeds need no login either.

Then run the test suites: `pnpm -r test` (~30 s) and `cargo test --workspace` (~30 min on a cold
machine, ~20 of them in the contract sandbox, which needs `wasm32-unknown-unknown` and `cargo-near`;
`cargo test --workspace --exclude tilt-house-contract` skips it).

One rules crate (`core/`) is compiled into the contract, the session server and the simulator; the
TypeScript verifier is checked against vectors generated by the Rust code
(`session-server/tests/vectors.rs` → `web/src/near/session-vectors.json`).

## Live endpoints

- Site: https://tilt-house-beta.vercel.app (guided tour: `/?tour=1`)
- Live NPC gamblers: `GET https://tilt-house-beta.vercel.app/session/gamblers/floor`
- A session's rounds: `GET https://tilt-house-beta.vercel.app/session/sessions/<id>`
- Poker tables and finished hands: `GET https://tilt-house-beta.vercel.app/session/poker/tables`, `…/poker/tables/<id>/hands/<n>`
- Contract views (`get_floor`, `get_lobby`, `get_session`, `get_player`, `get_config`, `get_npcs`, `contract_source_metadata`) on
  `floor.tilthouse.testnet` through any NEAR testnet RPC, e.g. `https://test.rpc.fastnear.com`.

## Working on the code

- Money is integer tUSDC base units (6 decimals), never floats; amounts cross JSON as decimal strings.
- Game rules live only in `core/`; never duplicate them elsewhere.
- Borsh enums in `core/src/session.rs` are only appended to: settled sessions hash old encodings.
- Testnet only. Never commit keys; they live in `~/.near-credentials/` or ignored `.env` files.
