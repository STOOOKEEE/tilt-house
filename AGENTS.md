# Tilt House: guide for AI agents (Claude Code, Codex)

You are evaluating or working on Tilt House, a casino tycoon on NEAR testnet: players own tables,
24 NPC gamblers with their own NEAR wallets are the customers, rent fills an on-chain jackpot, and
every round is provably fair. Human overview: `README.md`.

## Evaluate it in 5 commands

Node 22+, pnpm, Rust stable. No keys, no config: everything targets the public testnet deployment.

```sh
pnpm install
pnpm --filter cli-demo floor                                          # the live economy right now
pnpm --filter cli-demo demo --new                                     # play on testnet with a fresh account, verify every round
pnpm --filter cli-demo poker                                          # two accounts play hold'em with the NPC bots, every hand verified
pnpm --filter cli-demo verify-session --player g-mia.tilthouse.testnet  # verify an NPC gambler's session
cargo run -p tilt-house-sim --release -- --days 7 --seed 42 --out /tmp/tilt-sim.json  # a simulated week
```

All CLI commands exit 0 only when every check passes; a failed check prints `✗` with the reason.
`demo` makes its own throwaway testnet account (key in `~/.tilt-house/cli-demo-account.json`).

Then run the test suites: `cargo test --workspace` and `pnpm -r test`.

One rules crate (`core/`) is compiled into the contract, the session server and the simulator; the
TypeScript verifier is checked against vectors generated by the Rust code
(`session-server/tests/vectors.rs` → `web/src/near/session-vectors.json`).

## Live endpoints

- Site: https://tilt-house-beta.vercel.app (guided tour: `/?tour=1`)
- Live NPC gamblers: `GET https://tilt-house-beta.vercel.app/session/gamblers/floor`
- A session's rounds: `GET https://tilt-house-beta.vercel.app/session/sessions/<id>`
- Poker tables and finished hands: `GET https://tilt-house-beta.vercel.app/session/poker/tables`, `…/poker/tables/<id>/hands/<n>`
- Contract views (`get_floor`, `get_lobby`, `get_session`, `get_player`, `get_config`, `get_npcs`, `contract_source_metadata`) on
  `floor.tilthouse.testnet` through any NEAR testnet RPC, e.g. `https://test.rpc.fastnear.com`.

## Working on the code

- Money is integer tUSDC base units (6 decimals), never floats; amounts cross JSON as decimal strings.
- Game rules live only in `core/`; never duplicate them elsewhere.
- Borsh enums in `core/src/session.rs` are only appended to: settled sessions hash old encodings.
- Testnet only. Never commit keys; they live in `~/.near-credentials/` or ignored `.env` files.
